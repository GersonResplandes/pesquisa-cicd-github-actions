# Origem das evidências

`locais/`: registros originais do ensaio exploratório em Windows, com caminhos pessoais removidos dos logs. As versões originais do pipeline no histórico continuam ignorando `evidence/` e `dist/`.

`github/`: cópias dos resultados e logs provenientes dos artefatos das execuções hospedadas, identificadas pelas URLs públicas e pelo commit de execução.

Uma cópia publicada não substitui a consulta à execução correspondente no GitHub Actions. Consulte o índice de provas para distinguir execução válida, falha deliberada e recuperação.
